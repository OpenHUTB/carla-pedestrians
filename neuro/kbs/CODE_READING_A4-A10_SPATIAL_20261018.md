# A4–A10 空间细胞与经验地图：代码阅读笔记（写作原料，非论文文本）

用途：重写方法章 3.7（内嗅皮层）、3.8（海马经验地图与闭环）前，先读懂真实实现。只讲代码事实。主文件：`01_conjunctive_pose_cells_network/3d_grid_cells_network/gc_iteration.m`（207 行）、`get_gc_xyz.m`（97 行）、`02_multilayered_experience_map/exp_map_iteration.m`（625 行）、`create_new_exp.m`（100 行）。

## 一句话

空间记忆是一个 **36³ 的连续吸引子网络**（RatSLAM 式，非 FPGA 式大网格）：视觉模板重访时向对应单元注入能量，每步做"局部激励卷积 → 局部抑制 → 全局抑制 → 归一化 → 按融合速度移位（路径积分）"；位姿从活动包的圆均值读出；经验地图在网格/HDC 索引空间上建节点、极坐标建边、逐边迭代松弛。论文现稿的 FCC 晶格、Hebbian 关联矩阵、五步环路残差松弛均不存在。

## 3.7 网格细胞网络本体（gc_iteration.m，文件头注释即六步流程 L27-33）

**网络与核常数**（驱动 `test_imu_visual_fusion_slam.m`）：
- 网络 `GC_*_DIM=36`（三维各 36 单元）；激励核 `GC_EXCIT_*_VAR=1.5`（L208）、抑制核 `GC_INHIB_*_VAR=2`（L211）——高斯核宽是 1.5 不是旧稿的 5，且**抑制核存在**，旧稿漏写
- 全局抑制 `GC_GLOBAL_INHIB=0.0002`（绝对阈值）；VT 注入能量 `GC_VT_INJECT_ENERGY=0.5`；读出包窗 `GC_PACKET_SIZE=4`（L218）
- 无 FCC 晶格、无 12 最近邻——激励/抑制都是**稠密 3D 权重张量 + 模 N 环绕索引**（`GC_EXCIT_*_WRAP`，L109-115）

**① VT 能量注入**（L87-100）：非新模板重访时，向该模板关联单元加能量
`energy = GC_VT_INJECT_ENERGY × (1/30) × (30 − exp(1.2 × decay))`（L96）。
decay 随时间增长 → 注入量衰减 → **必须多次一致重访才能捕获网络**（注释 L92-95 明说这是防静止时坏匹配误捕获的机制）。这是旧稿"Hebbian 关联矩阵 Ξ + 矫正注入"的真实对应物——没有学习矩阵，只有带衰减的单点注入。

**② 局部激励**（L102-120）：每个非零单元与其激励权重张量卷积（环绕边界），等效"活动包扩散加强"。
**③ 局部抑制**（L122-140）：减去抑制核卷积，锐化活动包。
**④ 全局抑制**（L144）：`(GRIDCELLS >= 0.0002) .* (GRIDCELLS − 0.0002)`——**绝对阈值**软削减，不是旧稿的 λ·Ā 均值比例式。
**⑤ 归一化**（L148-149）：全网络 L1 归一。

## 3.7 路径积分（L152-205）——旧稿 floor(γvΔt) 的真实版本

xy 平面按航向分三种：
- **四个基向**（0°/90°/180°/270°）：精确单行 circshift，权重 `(1−transV)` 与 `transV`（L156-167）——是**分数权重混合**，不是整数移位。
- **一般角**：先按 90° 整数倍 `rot90` 旋转网络（L172），残角 dir90 用**双线性四邻权重**（L180-185：`w_sw=transV²·cosθ·sinθ`、`w_se=transV·sinθ−w_sw`、`w_nw=transV·cosθ−w_sw`、`w_ne=1−其余`）对旋转后平面做四方向 circshift 混合，再回卷边界、转回原坐标系（L187-192）。这是把连续平移离散化的标准双线性技巧——值得如实写，比编造的 floor 公式漂亮且真。
- **z 轴**（L197-204）：`heightV/GC_Z_TH_SIZE` 的整数部分 + 余数权重做 floor/ceil 两档 circshift 混合。

## 3.7 位姿读出（get_gc_xyz.m）——不是全网质心

- 找最大激活单元（L64-66）→ 只取其 ±`GC_PACKET_SIZE`(=4) 邻域窗（L69-76）。
- 窗内沿 x/y/z 各做 **sin/cos 圆均值**（预存查找表 L78-95）：`gcX = mod(atan2(Σsin, Σcos)/GC_X_TH_SIZE, GC_X_DIM)`。
- 即"活动包峰值 + 局部圆均值"读出，输出**网格索引坐标**（乘 cell size 才是米制）；不是对全网做 population vector。

## 3.7 HDC（36×36 yaw×height）

`YAW_HEIGHT_HDC_*_DIM`：方位 36 箱 × 高度 36 层（不是旧稿 360×5）。动力学与网格细胞同族（激励/抑制/归一），航向速度驱动移位。经验匹配里高度维度参与 delta_em（见下）。

## 3.8 经验节点创建与匹配（exp_map_iteration.m）

**累积位移**（L136-141）：`ACCUM_DELTA_X += transV·cos(ACCUM_DELTA_YAW)`，yaw 累加后 clip 到 ±180°——航位推算馈入地图。

**delta_em 判据**（L146-159）：当前 GC 读出与当前经验锚点的五维**环绕最短距离**：
`delta_em = √(Δx²+Δy²+Δz²+Δyaw²+Δheight²)`（GC/HDC 索引空间，yaw 取正向与**反向**的较小者 L153-154）。阈值 `DELTA_EXP_GC_HDC_THRESHOLD=20`（驱动 L97）。

**创建规则**（L170-176 + 注释 L168-169）：
- VT 从未见过（`numExp==0`）→ 直接建新节点；
- VT 换了但见过 → 在该 VT 关联的经验里搜 delta_em<20 的候选（L197-218）。

**多候选消歧**（L194-239，哈希碰撞防护，注释 L193 明说）：
- 唯一候选 <20 → 匹配；
- 多候选 → 比率门 `vals(1)/vals(2) < EXP_MATCH_RATIO_THRESHOLD` 才接受最优（L224-235），否则维持原经验——**宁留旧不建错边**。

**闭环接受的三重几何门**（在经验层，区别于部署帧级四重门）：
1. 比率门（上）；2. **CE 门** `EXP_MAX_LOOP_CE`（L241-254）：用累积位移推算的期望位置与候选节点地图位置的偏差超限则拒；3. **朝向门** `nl_apply_loop_fix`（L258，[B-fix] 注释：朝向门+修正传播，0=拒绝落回建新节点）。

**边的表示**（create_new_exp.m L41-51）：**极坐标**——`d_xy=√(Δx²+Δy²)`、`d_z`、`heading_yaw_exp_rad`（指向新节点的方位，相对当前节点朝向）、`facing_yaw_exp_rad`（新节点朝向差）。不是旧稿的 (Δx,Δy,Δz,Δψ) 笛卡尔四元组。

**EKF-odo 钉扎**（L72-88）：`NLM_EKF_ANCHOR_MAP` 非空时新节点坐标 = 创建帧 EKF 地图系位置 + `NLM_LOOP_CORR`（闭环累计修正继承，注释 L78-79：否则闭环一离开匹配节点即被抹掉）；非 EKF-odo 路径仍用 `父节点 + ACCUM_DELTA` 累加（L85-87）。**这段注释本身写得很清楚，重写时照着理解即可。**

## 3.8 地图松弛（L439-495）——不是五步环路残差

`for i=1:EXP_LOOPS(=8)` 外层轮数 × 遍历所有经验的全部 link：
- 由 e0 的 link 推算"e0 认为的 e1 位置" `(lx,ly,lz)`（L459-461，极坐标回笛卡尔）；
- e0、e1 各按 **EXP_CORRECTION=0.4** 等量反向修正位置（L474-480，注释：0.5 意味着完全修正）与 facing 角（L484-490）；
- 记录最大约束误差 `EXP_CONSTRAINT_ERR_MAX`（诊断量）。

逐边迭代松弛，无"找环路→残差→按 |P| 均摊→重锚"四步。**EKF-odo 模式下松弛整体禁用**（驱动 L122-123 注释：钉扎节点坐标已是 EKF 真值，但 link 存的 d_xy/heading 是 DR 值，松弛会把真值拉歪）。

## 重写提示（各节通用）

1. **先讲清"索引空间"**：整个吸引子网络与经验地图运行在网格单元索引坐标系（cell size 换算米制），所有距离（delta_em、阈值 20）都是索引单位——旧稿把它混写成米制是概念错误。
2. **"衰减注入替代学习"**是本系统最值得如实强调的设计：防错误捕获的机制写在代码注释里（gc_iteration L92-95），一句话就能讲清，且与生物学"多线索一致性"叙事天然契合。
3. 六步循环（注入→激励→抑制→全局抑制→归一→积分）就是文件头注释的原结构（L27-33），按这个顺序写 3.7 最自然，也和代码一一对应。
4. 经验层三重门（比率/CE/朝向）与部署帧级四重门是**两级不同的闭环**：前者管经验图拓扑，后者管度量重锚。旧稿把两者混在一节里，重写时分开放。
5. 所有阈值（20/0.4/8/0.08/0.5/0.0002/4/1.5/2）都在驱动 L96-120 与 L199-218 有唯一出处，写数值时照抄即可；VT_MATCH_THRESHOLD=0.08 是默认值、逐数据集可覆盖（L102-104），别写成全局常数。
