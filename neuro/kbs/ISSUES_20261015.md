## 一、三大结构性缺口 (论文级)

### 缺口1: 无外部基线对比
- **问题**: 只跟自研 EKF 跟踪核比, 没跟公开 VIO/SLAM (ORB-SLAM3 / VINS-Fusion 等) 比。学位论文通常可接受, 期刊/会议会被问 "为什么不跟 SOTA 比"。
- **侦察结论** (已完成):
  - KITTI 官方里程计指标 = **相对平移误差 RTE(%)** (逐帧位移幅值、对尺度敏感)。排行榜: 立体视觉 0.5-1.2% (SOFT2 0.53% / SOFT-SLAM 0.65% / VINS-Fusion 1.09% / ORB-SLAM2 1.15%), 激光 ~0.5%, 单目差 (MonoROCC 1.11% / MonoDepth2 12.59%)。
  - **官方 RTE 口径与 NLM 价值不匹配**: 它衡量逐帧里程计质量, NLM 的价值在全局一致性 (ATE/闭环/尺度校正)。拿我们 KITTI 轨迹算官方 RTE 会 ~95-100% (被 1.9× 尺度偏拖累), 但那反映的是数据质量, 不是 VIO 真实水平。
  - **T1a 实数 (2026-10-16 实测, 复现: `python3 kitti_rte.py` 扩展版)**: 官方 RTE 无对齐 EKF 94.72% / NLM 101.06%; **Sim(3) 对齐后 (对单目最有利口径) EKF 72.09% / NLM 75.15%**; 剔离群帧 top-50 后仍剩 **38.20% / 46.91%** → 不是少量脏帧, 是**系统性逐帧尺度漂移** (per-frame 位移比 1.9×, 全局 Procrustes 尺度仅 1.24×, 非均匀拉伸)。**与缺口 2 同根因** (全局尺度不可恢复, S.1), 逐帧投影。
  - **T1a 结论**: 可行且与现有诚实框架自洽 — 外部对比"证实" S.1 已声明的尺度局限。写法: 主表 ATE 为主, RTE 进补充材料 + 定位段 (公开方法多为立体/带尺度标定, 低 RTE 反映尺度一致下的逐帧质量; NLM 价值在全局一致性 ATE 22.09→18.45m −16.5%)。诚实代价: "VIO 之上的闭环层"叙事在 KITTI 上被削弱 (核心逐帧质量实际差), 用 "核心是 up-to-scale VIO" 挡。
- **实跑成本** (若老师要求 T1b 头对头): KITTI 07/09 数据已在盘 + 管线已重建; 剩编译 ORB-SLAM3/VINS-Fusion + 单目配置 + 跑/评 ≈ 1 周。
- **状态**: 🟡 数据端已清 (07+09 在盘, 管线 `kitti_prepare_fusion.py`); T1a 侦察完成; 待老师拍板 **T1** (对比深度: T1a 文献表 vs T1b 实跑) + **T2** (目标期刊) + **T3** (deadline)。

### 缺口2: "度量"主张名不副实 (全局尺度偏置)
- **问题**: 主张 "无 RTK/GNSS 度量 SLAM", 但轨迹全局尺度偏 s=0.83-1.92 (应≈1)。全系统 sim3 拟合 s: T05 1.507 / T03 1.143 / T07 0.829 / T10HD 1.918 / KITTI 0.791。
- **现状**: "度量" 只在 "SE(3) 下超 EKF" 意义上成立 (5/5), 不在 "轨迹尺度 s≈1" 意义上。
- **"第3个 train-once 全局尺度头" 不可行** (已判死): 全局尺度是每场景 1 个标量, 需 "每场景 (特征, 尺度标签)" 训练对, 但只有 3 个 CARLA 训练场景 = 3 个训练点, 无法泛化到零样本。
- **可行路径** (待选型):
  - **(a) 气压计代理**: CARLA 有 GT 高度可模拟气压 → 定垂直尺度 → 定全局尺度。便宜, 但只撑合成侧, KITTI 无气压计。
  - **(b) IMU 尺度标定**: 全局尺度偏根因是 IMU scale bias 未标定, 标定 (1 参数) 从根上修, CARLA/KITTI 都可行, **但动 EKF, 与 "EKF 基线不变" 约束冲突**, 需谨慎。
  - **(c) 主张收缩**: 定位 "全局尺度意义下的度量 (up to global scale), SE(3) 下超 EKF", 零成本但削弱卖点。
- **收益证据**: KITTI 施加全局尺度修正 (×0.80) 使 SE(3) ATE 30.45→22.11m (**−27%**) → 修全局尺度收益明确。
- **状态**: 🔴 待老师定验收标准 (SE(3)胜 vs s≈1) + 路径选型 (a/b/c)。

## 二、KITTI 数据/结果问题 (诊断, `kitti_rte.py`)

### A. EKF 有 ~1.2s 异常高速区 (帧 690-701)
- **证据**: 每帧位移 5.1→5.3→…→7.1→**133.0**m (帧701), 另帧1098=6.5m; 折算 50-1300 m/s, 物理不可能。NLM 同区 (696-701) 峰值 85.4m (比 EKF 133m 小, NLM 部分压住), 另 431=7.1m / 1063=25.9m。
- **性质**: 一段 VIO 失效区, **非孤立跳变**。
- **影响**: 次要 —— 剔除 13 离群帧后 EKF sim3 仅 22.09→20.68 (−1.4m), NLM 18.45→17.69 (−0.76m)。

### B. KITTI 环未闭合 (EKF 和 NLM 都没闭)
- **证据**: 起-终点距 GT **9.43m** (走一圈回来) / EKF **130.42m** / NLM **132.85m**。
- **影响**: KITTI 上闭环线没把环闭上 → 那格的 "闭环" 叙事不成立。

### C. KITTI 的 "NLM 胜" 是中段形状校正, 非闭环, 且很薄
- **证据**: NLM sim3 18.45 vs EKF 22.09 (−3.64m, −16.5%); 但 SE(3) 仅 29.99 vs 30.45 (−0.46m, **−1.5%**)。NLM 末帧误差 90.6m > EKF 77.6m; NLM 端点 132.85m > EKF 130.42m。
- **结论**: NLM 的闭环事件把中段拉向 GT (形状校正), 但没闭合环、端点漂移略增。**5/5 全胜里 KITTI 是最脆弱一格**, 且不是闭环演示。

### D. 误差主体是系统性漂移 + 尺度, 非离群
- **证据**: 剔除离群仅降 1.4 / 0.8m (见 A); 全局尺度修正降 8.3m (SE3 30.45→22.11)。
- **结论**: 修尺度/漂移才是 KITTI 主杠杆, 修离群收益小。

### E. (好消息) KITTI "EKF" 确认为真 VIO, 非 GT 衍生弱基线
- **证据**: 对齐后误差随路线累积 (中点 17.2m → 末帧 EKF 77.6m / NLM 90.6m), 非有界噪声。
- **结论**: "NLM 胜 EKF" 是**公平对比**, 之前 "对坏基线薄胜" 的担忧不成立。

## 三、评测口径问题

### F. sim3 拟合 s 在往返/闭环路线上低估真实尺度偏置
- **证据**: KITTI sim3 拟合 s=0.808 (点云对齐尺度), 但逐帧中位尺度比 ~1.3-2.2× 且随时间漂移 (分段 1.355→1.310→1.190→1.178→2.162)。两者不一致, 因 GT 是闭环 (692m 路径/9.4m 端点) 而 EKF 是开环 (1320m/130m), 点云尺度 (s) 与逐帧位移尺度 (比) 失真。
- **影响**: 一直用 sim3 拟合 s 量化 "全局尺度偏置", 在往返路线上这个量失真, 需换逐帧位移口径或注明。

### G. 官方 KITTI RTE 口径与 NLM 价值不匹配
- (同缺口1) 官方 RTE 衡量逐帧里程计, NLM 价值在全局一致性 (ATE)。拿官方口径比会低估 NLM。
