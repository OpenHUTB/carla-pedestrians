\begin{abstract}
    \sloppy
    受脑启发的空间认知为自主定位提供了可解释的替代方案，用以替代不透明的学习方法。然而，现有的受脑启发框架仍局限于2D环境或简化的视觉处理，在困难条件下缺乏鲁棒的3D空间表征。为克服这些局限，本文提出 NeuroLocMap——一个将定位-建图框架扩展到4自由度状态估计的受脑启发框架，融合了前庭-视觉互补融合与海马-内嗅空间表征。该框架由双流视觉处理（腹侧通路负责识别、背侧通路负责运动）、前庭IMU建模、用于位置编码的3D网格细胞连续吸引子，以及用于闭环检测的经验式认知建图组成；在10状态EKF核之上，两个高层校正补全系统：在线的、仅尺度的单目校正（冻结深度基础模型之上的轻量回归头）与基于学习嵌入的闭环线。在涵盖仿真城市驾驶（CARLA Town05/03/07/10HD）与真实高速公路驾驶（KITTI~07）的五个场景上的实验表明，全系统\emph{在两种评估口径下于全部五个场景上优于}10状态EKF视觉-惯性基线——在仅形状的全Sim(3)重拟合（吸收全局尺度的上界）下改善16.5--59.3\%，在更严格的SE(3)刚性对齐（错误度量尺度无法被吸收）下改善1.5--33.9\%——并相对单目视觉里程计改善33.7--68.8\%。在专门的闭环基准上，经验地图重锚定相对EKF基线多恢复15倍累积全局漂移（55.92~m 对 842.54~m 锚定Sim(3)口径）。\textcolor{red}{参考实现}以实测39--76~FPS运行于CPU（无GPU），其学习组件一次训练、零样本部署，并输出可解释的拓扑经验地图。
\end{abstract}

\section{引言}
\label{sec:intro}

在复杂3D环境中的空间定位与建图是自动驾驶、移动机器人与智能交通系统的基石~\cite{cadena2016past}。作为自主设备的核心感知模块，SLAM直接支撑所有自主运动规划与执行。现代实用方案通常组合相机、IMU，有时还加入GNSS，以实现鲁棒的位姿估计~\cite{saputra2018visual}。传统SLAM方案大多采用优化或滤波框架求解位姿，但在模型可解释性与计算资源消耗上通常存在明显缺陷。

有趣的是，蝙蝠等生物通过融合视觉与前庭信号以及海马空间细胞完成3D导航~\cite{jeffery2013navigating,hafting2005microstructure,taube1990head,finkelstein2016three,solstad2008representation}。这些神经机制使受脑启发的定位框架在可解释性与计算效率上优于传统SLAM。

然而，将这些生物学原理转化为实用的机器人系统面临若干挑战。第一，现有仿生框架大多在2D中运行，而实际部署需要鲁棒的3D空间表征。第二，经典视觉模板匹配对光照与视角变化敏感，限制了困难环境下的地点识别性能。第三，一种将视觉里程计与惯性测量相结合、且不依赖EKF等计算昂贵滤波器的简单而有效的融合策略，在受脑启发定位框架中仍未被充分探索。

为应对这些挑战，本文提出 NeuroLocMap——一个扩展到3D空间内4自由度位姿估计（位姿 $x$、$y$、$z$、$\psi$）的受脑启发定位-建图框架，集成了双流视觉前端（腹侧通路用于场景识别、背侧通路用于运动提取）与前庭前端（用于IMU处理），并以\textcolor{red}{实例化为固定维数EKF的频域融合核}实现多感官融合。该框架采用3D网格细胞与多层头部方向细胞进行空间表征，并采用作为类海马情景记忆的多层经验地图用于地点识别与漂移校正。对于在相对平坦地形（如城市道路、室内地面）上运行的地面车辆，姿态由偏航角 $\psi$ 主导，俯仰与横摆变化通常受车辆动力学约束（$<5^\circ$）。我们的4自由度表征为这类场景提供了高效的定位-建图~\cite{milford2004ratslam,milford2010persistent}。

本文的贡献总结如下：
\begin{itemize}
    \item 我们提出一种统一的受脑启发架构，将双流视觉处理与前庭建模、海马-内嗅空间表征耦合，用于4自由度定位与建图。
    \item 我们开发了受皮层启发的视觉处理，采用显式算子构建视觉模板，将模板数从5（RatSLAM典型值）提升到评估序列中最多的964个（提升192倍以上），从而在困难光照与视角变化下实现更细粒度的地点判别。
    \item \textcolor{red}{我们设计了一种轻量前庭-视觉融合核，其每次更新的代价与跟踪视觉特征的数量无关：两种模态的频域互补性实例化为带五个门控观测分支的固定维数（10状态）松耦合EKF。两个一次训练的校正支路——冻结单目深度模型之上的在线仅尺度头与学习嵌入闭环线——随后叠加其上并零样本部署。完整流水线仅运行于CPU并维持39--76~FPS（参考前端，含评估与绘图）。}
    \item 我们在五个多样化场景（CARLA Town05 / 03 / 07 / 10HD，KITTI~07）上验证该框架：全系统\emph{在两种评估口径下于全部五个场景上优于}10状态EKF视觉-惯性基线（Sim(3)仅形状上界：$+$16.5--59.3\%；SE(3)刚性：$+$1.5--33.9\%），相对单目VO改善$+$33.7--68.8\%，且在专门的闭环基准上其经验地图重锚定相对EKF多恢复15倍累积全局漂移（55.92~m 对 842.54~m 锚定Sim(3)口径），同时将可解释的拓扑经验地图作为定位的副产品输出。
\end{itemize}

\section{结论}
\label{sec:conclusion}

随着资源受限环境下对鲁棒、可解释定位系统需求的增加，实现生物学合理的空间表征已成为自主导航与移动机器人不可或缺的一环。本研究提出 NeuroLocMap——一个受脑启发的4自由度定位-建图框架，将3D网格细胞与多层头部方向细胞的计算模型同双流视觉处理、互补前庭-视觉融合相结合。我们描述了受脑启发的空间细胞架构、受腹侧/背侧通路启发的双流视觉处理策略，以及用于多感官集成的\textcolor{red}{轻量频域融合核（以固定维数EKF实现）}。在五个多样化场景（CARLA Town 05 / 03 / 07 / 10HD，KITTI~07）上的实验结果表明，NeuroLocMap 全系统\emph{在两种评估口径下于全部五个场景上优于}10状态EKF视觉-惯性基线——仅形状的全Sim(3)重拟合下$+$16.5--59.3\%、SE(3)刚性对齐（错误度量尺度无法被对齐器吸收）下$+$1.5--33.9\%——并相对单目VO改善$+$33.7--68.8\%，同时保持\textcolor{red}{参考实现}实测39--76~FPS的CPU实时性能。在专门的闭环基准上，其经验地图重锚定相对EKF基线多恢复15倍累积全局漂移（55.92~m 对 842.54~m 锚定Sim(3)口径）。该框架将视觉模板数从约5个（RatSLAM典型值）提升到最多964个（提升192倍以上），使更细粒度的地点判别成为可能，支撑鲁棒的闭环检测。其学习组件——单目尺度校正头与闭环嵌入——仅在仿真上训练一次，即零样本部署于包括真实序列在内的每条测试序列；闭环线直接迁移，尺度头当前的sim-to-real差距\textcolor{red}{在实验中被量化}。未来工作将把该框架扩展到完整的6自由度位姿表征，弥合尺度支路的sim-to-real差距，并部署到神经形态硬件上，逐步实现可在嵌入式平台上实时运行的可解释定位系统。
